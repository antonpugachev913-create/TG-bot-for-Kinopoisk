# 🎬 Telegram Movie Recommendation Bot

Интерактивный Telegram-бот для поиска фильмов и получения персональных рекомендаций на основе актуальных данных платформы **Кинопоиск**. Проект разработан с использованием архитектуры конечных автоматов (FSM) для сохранения пользовательских предпочтений и бесшовной интеграции с внешним API.

---

## 🔥 Ключевой функционал

* **Умный текстовый поиск:** Мгновенное получение детальной карточки фильма (название, год выпуска, рейтинг Кинопоиска, описание, жанры и страны) по любому текстовому запросу.
* **Персональные предпочтения:** Интерактивный опрос пользователя (`/set_preferences`) для фиксации любимых жанров, фильмов и дополнительных критериев.
* **Автоматические рекомендации:** Подбор и фильтрация фильмов по сохраненным предпочтениям (`/recommend_movie`) напрямую через базу данных Кинопоиска.
* **Валидация и безопасность:** Защита от некорректных запросов и встроенная фильтрация системных команд Telegram при обращении к стороннему API.

---

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.11+
* **Фреймворк для ботов:** `pyTelegramBotAPI` (telebot)
* **Работа с сетью и API:** `requests` (синхронные HTTP-запросы, кастомные заголовки авторизации)
* **Менеджер зависимостей:** `Poetry` (полная изоляция окружения, детерминированные сборки через `pyproject.toml` и `poetry.lock`)
* **Хранение данных:** Локальное файловое хранилище (JSON) для долгосрочного сохранения предпочтений пользователей.

## 🚀 Быстрый запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```

2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```

3. **Настройте переменные окружения:**
   В корне проекта укажите ваши валидные токены в конфигурации:
   * `API_TOKEN` — Ключ доступа от [kinopoisk.dev](https://kinopoisk.dev)
   * Токен вашего бота в конструкторе `telebot.TeleBot`

4. **Запустите бота:**
   ```bash
   poetry run python main.py
   ```
